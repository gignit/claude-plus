# coder MCP

- This machine has the coder MCP server. In any project written in a language
  it supports (Go, TypeScript, C/C++, Python, Java), call the matching
  `mcp__coder__<language>_guide` tool once, early in the session, and follow
  it for the rest of the session, including refactors.
- Navigate code through coder tools; do not use `grep`, `head`, `sed`, or
  `cat` via Bash to inspect source files in supported languages.
